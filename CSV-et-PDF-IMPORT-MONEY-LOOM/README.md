## 📌 How to use

1. Click a CSV link → Click **"Download"** button (top right of GitHub page)
2. Open in Excel / Google Sheets / LibreOffice
3. Modify only cells marked with `*`
4. Save as UTF-8 `.csv`
5. Import into Money Loom app
