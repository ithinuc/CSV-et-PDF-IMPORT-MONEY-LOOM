📌 How to use / Comment utiliser / Wie verwenden / Cómo usar / 사용법 / 使い方 / Como usar / Paano gamitin

1. Download the CSV for your language → Open in Excel / Google Sheets / LibreOffice
2. Modify only the cells marked with * (do not change headers or === lines)
3. Use YYYY-MM-DD for dates, . for decimals, negative numbers for expenses
4. Save as UTF-8 encoded .csv file
5. Import into Money Loom app via the "Import" button

💡 Tip: Keep a backup of the original template before editing!
